# ナカカラモのテスト
- 公開する前・クラウドの見回りで、必ず `bash _tests/run.sh` を実行する。1つでも失敗したら公開しない。
- 不具合を直したら、`regress.js` の最後（「読み込み時にエラーが出ない」の前）に、その不具合がもう起きないことを確かめる項目を必ず1つ足す。項目は消さない・弱めない。
- フォルダ名が「_」で始まるので、サイト（nakakaramo.com）には公開されない。
- `bash _tests/run.sh people`：その日ごとにちがう架空の人を100人作って、全部の機能を使ってみる（同時に6人・約20分）。`N=10` で人数、`SEED=2026-11-27` で同じ日の人たちをやり直せる。毎日の見回りで使う。落ちた人だけやり直すときは `ONLY=R004 PEOPLE=100 SEED=その日 node _tests/features.js index.html`。
