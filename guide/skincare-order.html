スキンケアの正しい順番｜朝と夜の基本

更新：2026年11月28日

スキンケアの基本の順番は「洗う → 整える → 補う → 守る」です。水っぽいものから油っぽいものの順に重ねると、なじみやすくなります。

朝の順番

  1. 洗顔（ぬるま湯だけでもよい人もいます）
  2. 化粧水
  3. 美容液
  4. 乳液・クリーム
  5. 日焼け止め

夜の順番

  1. クレンジング（メイクや日焼け止めを落とす）
  2. 洗顔
  3. 化粧水
  4. 美容液（レチノールなどは夜に使う商品が多い）
  5. 乳液・クリーム

よくある迷い

  • 商品の説明書に順番が書いてあるときは、そちらに合わせます。
  • オールインワンは、化粧水〜クリームの代わりに1つで使えます。
  • 肌が荒れているときは、品数を減らして「洗顔・保湿・日焼け止め」の3つにしぼるのも1つの方法です。

ナカカラモでは、登録した化粧品を自動で朝・夜の順番に並べ、使い方のコツも一緒に表示します。
